# 题卡快批

面向一线教师的客观题批改小工具。教师可以生成答题卡模板，录入标准答案，上传学生答题卡图片或 PDF，系统自动识别学号和作答结果，并统计成绩、排名、均分与高频错题。

## 当前进度

- 当前主版本：V14
- 当前线上版本：以 `main` 分支根目录 `index.html` 为准
- 线上网址：`https://checkassistant.netlify.app/`
- 工具正式名称：题卡快批

目前 V14 已可用于小范围真实测试，已实现：自定义答题卡标题、答题卡生成、标准答案录入、答案文本自动识别、图片/PDF 上传批改、多班级统计、学生详情查看、异常识别手动修正、清空批改记录、成绩与错题统计、CSV 导出。

## 核心使用流程

1. 在“模板”页设置判断题和选择题数量，生成并打印答题卡。
2. 学生填涂答题卡。
3. 在“答案”页录入标准答案；也可以粘贴带题号的答案文本，系统自动识别判断题和选择题答案。
4. 在“批改”页上传学生答题卡图片或 PDF。
5. 如果识别不清晰，可手动修正学号、姓名或答案。
6. 在“讲评/成绩”页查看排名、均分、高频错题和错题学生名单。

## 重大修改记录

### 2026-08-12：统一界面与学号识别升级

- 将 1—4 页统一为“题卡快批”绿色教师工作台，保持原有创建、录入、批改和统计流程不变。
- 新增“待确认学号”：结合当前班级名册与每位数字的识别置信度生成候选，唯一可靠匹配自动补全，其余集中确认。
- 待确认卡片以手写姓名栏为主要核对依据，支持输入名册姓名确认，并可连续处理下一张答题卡。
- 保留确认前后的完整识别核对图，刷新页面后仍可人工检查。
- 学号识别改为双通道：答案区使用增强图，学号区保留浅色铅笔灰度；同时采用逐列相对评分，降低框线、印刷数字和浅涂造成的误识别。
- 使用 `3-2-619.pdf` 15 页回归：11 张完整识别、1 张名册自动补全、3 张进入人工确认。

### V14：自定义答题卡标题

- 模板页新增“答题卡标题”输入框。
- 打印模板、Word 模板和 SVG 模板都会显示自定义标题。
- 下载文件名会带上标题，方便区分不同考试或练习。

### V13：智能答案识别、手动修正与识别稳定性提升

- 支持自动识别带题号的答案文本，例如 `1. F 2. F ... 6. C ...`。
- 系统可根据题号自动区分判断题和选择题答案。
- 增加手动修正功能：识别不清晰时可以手动输入或修改学号、姓名、答案。
- 修复点击学生姓名无法查看答题卡详情的问题。
- 针对长方形答题卡优化识别逻辑，减少涂得偏浅、偏边、未完全覆盖时的漏识别。
- 对识别空白或可疑结果增加提示，避免系统静默给出错误结果。

- 各班级可以同时批改，但分开统计排名、均分和错题。

- 成绩统计支持按班级查看。
